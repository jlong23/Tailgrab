## Behavioural Changes
- Email and OTP Two Factor Authentication can now prompt the user for the 6 digit code.  If you leave the OTP Seed field blank, the system will now prompt you on startup to enter the 6 Digit OTP Code from your authenticator app. This will happen once the Cookies expire of VRC invalidates all sessions.
- ID search fields everywhere in the system will now handle pasting VRChat URLs and automatically extract the ID from the URL.  This includes User Profile, Group, and Avatar URLs.
- Exposing the Image URL of Emoji/Stickers and Prints in the log when fetched from VRC.
- Decreased the delay between each user profile request to VRC from 2 seconds to 1 second.  This will allow the system to process more users in a shorter amount of time, but may increase the risk of being rate limited by VRC.
- Removed the '--update' command line argument.  The system already checks the database schema version on startup and will prompt the user to update if needed.  The '--update' command line argument was redundant and unnecessary.
