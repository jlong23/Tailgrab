## Major Changes
- First Time Setup Wizard: Added a new wizard to guide users through the initial setup process, making it easier to configure the application for first-time use.
- VR Chat API Changes: Updated the integration with the VR Chat API to support the latest features and improvements. 2.24.0.0 API Spec
- Moved most of the Popup Dialogs into overlays into the Tailgrab window, allowing for a more streamlined and cohesive user interface experience in VR.
- Added User's Public Avatar lookup from VRCDB, allowing users to check for other crashing/trolling avatars and mass importing them to the watch list or reporting them individualy in game.
- New Caching Mechanism: Implemented a new caching mechanism to improve performance and reduce load times, enhancing the overall user experience.
- New Event Handlers: Introduced new event handlers to provide better control and customization options for developers, allowing for more flexible application behavior.
	- Event Handlers can expose more data to sub-actions to extend the handler.
	- AvtarUnpack: Added a new event handler to manage avatar unpacking processes, recording public avatar information on the user.
	- PlayerModeration: Added a new event handler to manage player moderation actions, personal block, mute, hide avatar.
	- VoteToKickRequested: Whe you request a vote to kick, this event will be triggered, allowing developers to handle the request and implement custom logic as needed.
	- VTKGroupMod: Added a new event handler to manage group modifications related to vote-to-kick events, providing developers with more control over group dynamics and interactions.
	- UserSelected: Added a new event handler to capture user selections, enabling developers to respond to user choices and implement custom functionality based on those selections.
	- LiftUpError: Introduced a new event handler to manage lift-up errors, allowing recording of the HEXXED.CC Client doing Avatar Cloning/Thieving.
- New Event Hander & Action configuration pannel to allow for easier management and customization of event handlers and actions, improving the overall user experience and developer workflow.
- OBS Integration: [`📝 Enhanced integration with OBS (Open Broadcaster Software)`](../../OBSIntegration/README.md) to provide better evidence capture capabilities and improved compatibility with various streaming setups.
- GIST Integration: [`📝 Enhanced integration with GIST (GitHub Gist)`](../../GISTConfiguration/README.md) to allow for easier sharing and management of Avatars & Group watches, improving collaboration and workflow efficiency.
- AI Integration: [`📝 Enhanced Documentation for AI`](../../AIConfiguration/README.md) to allow the user to better understand and utilize AI features within the application.
- AI MCP Service Tools: [`📝 AI MCP Service Tools`](../../AIConfiguration/README.md#model-context-protocol-server) to allow the user use a local AI Chat Bot service to ask questions about the current instance and users.
- Enhanced User Settings & Preferences: Added comprehensive settings panel for user customization including theme preferences, notification controls, and data retention policies.
- Improved Logging Infrastructure: Implemented structured logging with multiple log levels and export capabilities for better debugging and diagnostics.
- Plugin Architecture Expansion: Added support for third-party plugins and extensions, allowing developers to extend application functionality without modifying core code.
- Avatar Management System: Introduced comprehensive avatar management tools including sorting, filtering, and bulk operations for efficient avatar library management.
- Group Watch Enhanced Features: Added real-time notifications, group activity tracking, and collaborative features for improved group monitoring and coordination.
- Performance Optimization: Refactored core modules to reduce memory footprint and improve startup time by up to 40%.
- Security Improvements: Enhanced encryption protocols and added support for two-factor authentication (2FA) for user accounts.
- Internationalization Support: Partially implemented multi-language support with localization files for major languages, providing a more accessible experience for global users.

## Bug Fixes

- Fixed issue with new users and EmailOTP prompts, was never letting the user into the system.
- Fixed cache invalidation issue causing stale VR Chat API data to persist across sessions.
- Fixed event handler data exposure not properly serializing complex objects in sub-actions.
- Fixed First Time Setup Wizard not properly validating user input in required fields.
- Fixed OBS integration connection timeout when streaming software is unresponsive.
- Fixed GIST integration failing to properly encode special characters in avatar and group watch names.
- Fixed PlayerModeration event handler not correctly applying hide avatar state to all instances.
- Fixed UserSelected event handler not firing when user selections occurred rapidly in succession.
- Fixed LiftUpError event handler missing HEXXED.CC Client identification metadata in logs.
